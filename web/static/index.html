Cómo funciona

No tienes que instalar nada: la conversión se hace en nuestro servidor, no en tu equipo. Funciona desde el navegador del ordenador, la tablet o el móvil, cuando lo necesites y estés donde estés.

Lo que otros conversores rompen

Un PDF describe dónde va cada letra en una página de tamaño fijo, no qué es un párrafo, una cabecera o un pie de figura. Muchos conversores copian el texto tal cual y el libro se llena de números de página, palabras cortadas e imágenes sueltas. Este reconstruye el libro.

Enviar al Kindle

  1. Descarga el archivo .epub desde esta página.
  2. Súbelo en Enviar a Kindle (la web de Amazon). Es la opción más fiable y admite los archivos más grandes.
  3. Para archivos pequeños también puedes enviarlo por correo a tu dirección @kindle.com.

Si es la primera vez que usas el correo, añade tu dirección de envío a la lista de correos autorizados en la configuración de tu cuenta de Amazon.

Los que tienen texto digital, es decir, en los que puedes seleccionar el texto: libros, manuales, artículos. Si es un escaneo, activa el OCR en las opciones.Los escaneos (páginas que son solo una foto) salen como imágenes de página, sin texto reconocido. Para cómics, partituras o mucha matemática, elige «páginas como imagen».

Por las imágenes: se guardan con resolución suficiente para ampliarlas en el Kindle. Un libro con muchas figuras puede pesar tanto como el PDF o más. Si pasa de 25 MB, envíalo con la web Enviar a Kindle.

Esas páginas no tenían texto legible en el PDF (escaneadas o con texto dañado), así que van como imagen para no mostrar texto erróneo. Si es un escaneo, vuelve a convertir con el OCR activado.
